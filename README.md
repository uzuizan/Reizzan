# Guitar Store Inventory Manager — Set B

Practical Exam project built with React + Vite.

## Requirements covered

- Single Page Application using React (Vite)
- CSS styling
- `useState` for controlled form, validation, records, filter, and selection
- `useEffect` for active-row/profile synchronization
- Form validation:
  - Guitar Model: minimum 3 characters
  - Body Type: Electric, Acoustic, Bass, Classical
  - Stock Quantity: 1–100
  - Manufacturer
  - Merchant / Consumer radio buttons
- TanStack Table (`@tanstack/react-table`)
- Client-side pagination with 4 rows per page
- Row selection
- Search and in-stock filter
- Active item profile card
- Responsive layout

## Run

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build

```bash
npm run build
```
